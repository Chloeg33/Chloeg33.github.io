# Chloe的课堂空间站 (Chloe's Classroom Space Station)

一个交互式英语学习网站，专为学生提供有趣的英语学习体验，包括测验和游戏功能。

![版本](https://img.shields.io/badge/版本-1.1-pink)
![状态](https://img.shields.io/badge/状态-开发中-purple)

## 项目概述

Chloe的课堂空间站是一个互动性强的英语学习平台，旨在通过测验和游戏的方式，让学习英语变得更有趣、更高效。网站采用现代化的UI设计，以粉色和紫色为主色调，呈现出清新、活泼的风格，同时确保了良好的用户体验。

### 主要特点

- **响应式设计**：适配各种设备尺寸，包括手机、平板和电脑
- **现代化UI**：采用粉色紫色渐变风格，结合Apple设计美学
- **平滑过渡动画**：增强用户体验的页面过渡和元素动画
- **深色/浅色模式支持**：自动检测系统颜色方案（开发中）

## 功能模块

### 1. 交互式测验

网站提供多种英语学习测验，目前已实现：

- **学术词汇测验 01**：测试用户的基础学术英语词汇知识
- **学术词汇测验 02**：提供更多专业学术词汇测试，加深用户对学术英语的理解
- 测验包含选择题、填空题等多种题型
- 所有测验均带有计时功能，测验结束后会显示成绩和用时分析

### 2. 英语学习游戏（开发中）

英语学习游戏功能正在开发中，预计完成度75%：

- 预计发布时间：2025年3月
- 将提供多种互动游戏，帮助用户在娱乐中学习英语

## 技术架构

### 前端技术

- **HTML5**：网站的结构和内容
- **CSS3**：使用现代CSS特性实现响应式设计和动画效果
- **JavaScript**：实现网站的交互功能和动态效果
- **Bootstrap 5**：提供基础UI组件和响应式网格系统
- **Font Awesome 6**：提供丰富的图标资源

### 文件结构

```
├── css/
│   └── style.css       # 网站主样式文件
├── js/
│   ├── main.js         # 主要JavaScript功能
│   ├── quiz.js         # 测验相关功能（开发中）
│   └── games.js        # 游戏相关功能（开发中）
├── index.html          # 网站首页
├── quizzes.html        # 测验列表页面

├── quizze2.html        # 学术词汇测验02
├── games.html          # 游戏页面（展示开发进度）
└── README.md           # 项目说明文档
```
